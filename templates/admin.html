🛡️ System Threat Model (STRIDE Methodology)

Formal threat classification: Mitigated, Partially Mitigated, and Out-of-Scope boundaries

ℹ️ Threat Identification Methodology: Evaluates system trust boundaries across Browser Client, TLS Network Transit, Web Application Server, and SQLite Database using Microsoft STRIDE.
STRIDE Category Identified Threat Attack Mechanism Implemented Countermeasure Status
S - Spoofing Replay Attack Attacker sniffs valid authentication proof and resubmits it over the network. Fresh 128-bit client & server nonces, 60s TTL, single-use atomic consumption in SQLite. MITIGATED
S - Spoofing Session Fixation Attacker pre-sets a known session ID on victim before login. Session regeneration: issuing an unpredictable 256-bit token immediately upon login. MITIGATED
T - Tampering Transcript Tampering Attacker modifies username or nonces between handshake steps. Canonical AuthMessage transcript binding strictly verified via HMAC-SHA256. MITIGATED
I - Info Disclosure Password Theft in Transit Plaintext password intercepted on network or in server logs. Client-side WebCrypto: Plaintext password never transmitted; only PBKDF2-derived verifiers sent. MITIGATED
I - Info Disclosure Pass-the-Verifier / DB Exfiltration Attacker steals database and uses stored verifier to authenticate. SCRAM separation: Database stores StoredKey = SHA256(ClientKey). Proof requires ClientKey. MITIGATED
I - Info Disclosure Username Enumeration Probing endpoints to identify valid user accounts via error messages or salt variance. Deterministic synthetic salts; uniform challenge payload & identical generic 401 failure responses. MITIGATED
I - Info Disclosure Offline Dictionary Attacks on DB Compromise Attacker steals database and conducts offline dictionary search against stored verifiers. 100,000 PBKDF2 iterations and Argon2id integrity seal increase attacker cost; weak passwords remain vulnerable to dictionary search. PARTIALLY MITIGATED
D - DoS Online Brute-Force & Credential Stuffing Automated rapid online password guessing against active user accounts. Failed attempt counters, progressive delays, and temporary 5-minute lockout after 5 failures mitigate online guessing. PARTIALLY MITIGATED
E - Privilege Escalation Session Hijacking (XSS Cookie Theft) Malicious script accesses document.cookie to steal session token. Cookies configured with HttpOnly, Secure, SameSite=Lax. Token stored as SHA-256 hash. MITIGATED
Boundary Client Endpoint Compromise (Keylogger) Malware, trojans, or compromised browser extensions recording keystrokes on user machine. Outside application trust model; client environment integrity must be guaranteed by endpoint OS. OUT OF SCOPE
Boundary TLS Infrastructure MITM / Rogue CA Adversary controls rogue certificate authority or terminating proxy outside host. Network transport security relies on platform TLS PKI; mutual ServerProof detects untrusted authentication servers. OUT OF SCOPE
Boundary Quantum Cryptanalysis (Shor's / Grover's) Future large-scale quantum computers running cryptanalysis against SHA-256 and HMAC. Classical computational hardness assumptions; post-quantum cryptographic primitives are out of protocol scope. OUT OF SCOPE
